The Free Game Night Hosting Pack

Everything you need for an easy family card-game night, explained like a friend would: plain English, printable, and zero cost.

How to use this pack

Print any PDF at 100% scale on US Letter (8.5×11 in). Cardstock is nice for the rule cards, but plain paper works. Serve the site and PDFs with any local web server from the repo root — for example python3 -m http.server 8000 — then open http://localhost:8000/site/. Want to tweak the PDFs first? Edit scripts/generate_pdfs.py and run python3 scripts/generate_pdfs.py.

House rules are house rules: mark them up, laminate them, ignore them. If tonight had one laugh, it worked.
